# STAFFORA 
### People. Organized. Better.

STAFFORA is an Employee Management System built to make managing employee information easier and more organized.

The idea behind the project is simple: instead of keeping employee details scattered across different files or records, STAFFORA brings everything together in one place where an admin can manage and track employee information بسهولة.

---

##  About the Project

STAFFORA provides a simple way to manage employee records through a clean and user-friendly interface.

The system is designed for administrators who need to keep employee data organized, make updates easily, and get a quick overview of their team.

---

##  Features

- **Admin Authentication** – Sign up, log in, and reset password.
- **Dashboard** – View an overview of the team and employee statistics.
- **Employee Management** – Add, edit, view, and delete employee records.
- **Search** – Find employees by name, ID, email, or job title.
- **Filters** – Filter employees by department and employment status.
- **Multiple Views** – Switch between list and grid layouts.
- **Employee Profiles** – View detailed information for each employee.
- **Cloud Database** – Store and manage employee data using Firebase.

- Address

##  Application Structure

STAFFORA is built around two main parts:

**1. Admin Side**

The administrator can create an account, access the dashboard, and manage all employee records.

**2. Employee Records**

Employee information is stored and displayed in an organized way. Employees do not need to create accounts to be included in the system.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- A Firebase project

### Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd management_app_flutter
```

3. Install the dependencies:

```bash
flutter pub get
```

4. Configure Firebase for your project.

5. Run the application:

```bash
flutter run
```

---

##  Firebase Setup

STAFFORA uses Firebase for authentication and cloud data storage.

To run the project with your own Firebase configuration:

1. Create a project in Firebase Console.
2. Enable Email/Password Authentication.
3. Create a Cloud Firestore database.
4. Connect your Flutter application to Firebase.
5. Make sure your Firebase configuration files are set up correctly.
